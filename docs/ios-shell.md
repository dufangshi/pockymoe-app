# iOS thin shell

The app generated by `ios/project.yml` compiles `ios/Shell` and `ios/Shared`,
not the retired native product screens under `ios/RemoteCodex`. Those sources are
retained until the Web replacement passes the required product-flow E2E.
The bundle identifier remains `com.remotecodex.app`; its display name is Pockymoe.

A configured HTTPS origin owns one full-screen WKWebView. Debug additionally
accepts loopback HTTP for isolated tests. Release has no ATS exceptions.
The JavaScript host is injected at document start only into that origin's top
frame; native handlers independently check both the frame and current document.
Async replies are tied to a document generation. External links use the system,
and `auth.openExternal` uses ASWebAuthenticationSession with the existing
`remotecodex` callback scheme. The page owns the OAuth session handoff and all
routes, menus and back ordering. Mobile Preferences and pet methods are no-ops.

The page requests APNs registration and sends the returned token to the Relay's
existing native registration endpoint. The shell never registers an account
itself. Foreground notifications are suppressed; taps and activity links route
to the same WebView. No native durable-feed watcher runs in the new target.

## Live Activity wire format

`activity.sync` supplies local titles/device/workspace metadata. An App Group
cache makes that metadata available to the Widget extension, clearing it on
account changes. Agent rows group under their root conversation. One active
activity summarizes an account; another account's activity is ended immediately.
A new activity starts only with foreground running work. Waiting prevents ending.
After all work ends, the completed count remains for 15 minutes.

`PockymoeActivityAttributes` contains `accountId`. `ActivityContentState` is the
APNs `content-state`: `rows` (`key`, `state`, `startedAt`), `waitingCount`,
`totalCount`, `failedCount`, `runningCount`, `completedCount`, `earliestStart`, and nullable `endedAt`.
Rows are capped at three to stay below ActivityKit’s 4 KB budget; `totalCount`
provides the overflow label. The full batch tracking policy stays on the device.
Dates use Swift Codable's seconds since 2001-01-01 UTC. Each key is
`deviceId:threadId`. No title, device name, workspace, request or result text is
accepted in this state. Unknown rows display “线程运行中” and derive a thread link
from the identifiers. Relay updates use ActivityKit's `update` event; ending must
use APNs `end` with a dismissal date 900 seconds after the terminal timestamp.
The Relay must never use push-to-start. The shell delivers the activity token via
`onCommand({id,type:'liveActivityToken',token})`; the Web/Relay worker owns its
registration and APNs delivery. The live activity's token is separate from APNs
alert registration.

## Local checks

```sh
export DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer
(cd ios && xcodegen generate)
xcodebuild build -project ios/RemoteCodex.xcodeproj -scheme RemoteCodex \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO
swift test --package-path ios
node --test tests/ios-host.test.mjs tests/native-bridge.test.mjs
```

Create your own iPhone 17 Pro simulator, then use `IOS_SIMULATOR_ID=<uuid>` with
`scripts/e2e-ios.sh`. Start `scripts/e2e-backend.sh serve` separately with isolated
`E2E_RELAY_PORT` and `E2E_SUPERVISOR_PORT`. The helper clears inherited production
configuration and provisions a disposable encrypted account. Its Node fixture
uses `hash-wasm` from the control-plane Web package. Never print `.local` fixture
credentials. Stop the helper and your simulator when finished.

Debug-only `E2E_ACTIVITY_STATE` accepts `running`, `needsInput`, `failed`,
`overflow`, or `completed` at launch with `--uitesting`. It starts a local activity
before terminal fixtures; Release has no fixture driver. System screenshots in
XCTest are attachments in `.local/ios-results-*.xcresult`. They must be inspected:
a passing screenshot test alone does not prove that SpringBoard showed the island.

The shared legacy `web/native-bridge.js` and its tests remain for Android. iOS
loads only `web/pockymoe-host.js`.
