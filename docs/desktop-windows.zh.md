# Pockymoe Desktop：Windows 设计

Windows 版的体验以 Mac 版为准。同一个操作的入口、文案、时序和反馈都相同，只有下表列出的地方按系统习惯处理。总体设计见 [desktop-design-v3.zh.md](desktop-design-v3.zh.md)，界面规则见 Pockymoe 仓库的 `docs/ui-principles.md`。

支持 Windows 11 和 Windows 10 22H2，x64 与 arm64。

## 1. 按系统习惯处理的地方

| 项目 | Mac | Windows |
| --- | --- | --- |
| 窗口按钮 | 左侧红绿灯 | 右侧系统按钮（`titleBarOverlay`），高度与顶栏一致，颜色跟随页面主题 |
| 主窗口背景 | vibrancy | Windows 11 用 Mica；Windows 10 用页面的纯色背景 |
| 窗口圆角 | 系统 | Windows 11 系统圆角；Windows 10 直角，不用透明窗口模拟 |
| 快捷键 | ⌘ | Ctrl，界面上写「Ctrl」，不出现 ⌘、⌥ 符号 |
| 应用菜单 | 屏幕顶部菜单栏 | 隐藏，按 Alt 也不显示；所有快捷键仍然有效 |
| 常驻入口 | 菜单栏图标 + Dock | 通知区域图标 + 任务栏 |
| 角标 | Dock 角标 | 任务栏叠加图标 |
| 关闭主窗口 | 留在后台 | 同样留在后台，靠通知区域图标回来 |
| App 未运行时的提醒 | APNs | 不提供。不做 WNS，这是已知差距，要写在界面说明里 |

## 2. 字体

界面字体依次用 `Segoe UI Variable Text`、`Segoe UI`，中文用 `Microsoft YaHei UI`。字号、行高、字重与 Mac 相同。不要为了“看起来一样大”单独调字号；只有文字在控件里明显偏离垂直居中时才调行高，并在所有主题下复查。等宽字体依次用 `Cascadia Mono`、`Consolas`。

## 3. 浮层与桌宠

- 桌宠的角色窗口完全透明，没有边框、阴影和任务栏按钮，不抢焦点，只有画出来的像素能点中。全屏应用之上的表现与 Mac 一致。
- 玻璃浮层优先用 Acrylic。Acrylic 在无边框窗口上圆角不干净或拖动时闪烁的话，就改成完全不透明的纯色面板，配 1px 描边和 12px 圆角。干净优先于通透，不接受闪烁或方角露底。
- 贴边隐藏要算上任务栏，任务栏在哪条边都要正确。探头动画与 Mac 相同。
- 多显示器和 125%、150%、200% 缩放下，桌宠不漂移、不变形，跨屏拖动时大小不跳。

## 4. 托盘与角标

- 单击托盘图标与 Mac 单击菜单栏图标做同一件事，右键打开同一份菜单。
- 托盘图标按任务栏明暗切换，两种都要清晰。
- 任务栏叠加图标沿用 `ui-principles.md` §6 的状态语言：等待你用琥珀色对话气泡，只凭形状就能认出，并带可访问描述。没有需要注意的事情时不显示。

## 5. 通知

使用系统 Toast，标题、正文、操作按钮和点击后的去向与 Mac 相同。同一事件不能同时弹 Toast 和重复的桌宠气泡，规则同 v3 §2.7。App 的通知名称和图标必须是 Pockymoe，不能显示 `electron.app` 或应用 ID。

## 6. 控件

沿用 v3 的规定：不出现系统原生控件的外观。例外只有系统文件选择框和托盘右键菜单。滚动条用共享的自绘滚动条，不能露出 Windows 默认滚动条。

## 7. 安装

NSIS 按用户安装，不要求管理员权限，也不弹 UAC。安装过程只有进度，没有向导页。开始菜单和桌面快捷方式的名称都是 Pockymoe。卸载时默认保留用户数据。

## 8. 验收

在 Classic、Plum Pocket、Terminal 三个主题的浅色和深色下，分别在 100% 和 150% 缩放下截图检查主窗口、线程地图、设备页、偏好设置、快捷窗口、桌宠与浮层。截图和测试结果都要来自真实的 Windows 环境，不能用 Mac 上的结果代替。

## 实机修订

- Cmd/Ctrl+0 只打开地图；「实际大小」在所有平台都没有快捷键。
- 常驻说明按平台写「通知区域 / notification area」或「菜单栏 / menu bar」。
- 按用户安装的目录为 `%LOCALAPPDATA%\Programs\Pockymoe`，不更改 appId 或更新身份。

- Acrylic 的快捷窗口和玻璃面板使用至少 85% 的主题背景 tint；当前固定为 96%。浅色、深色均如此。
  所有文字颜色在最坏的白色或黑色桌面背景上保持至少 4.5:1 对比度，不能靠截图透明底冒充原生效果。
  纯色 fallback 完全不透明。此修订只作用于 Windows，不改变 Mac 材质或颜色。

- 主窗口的原生按钮背景与符号颜色使用网页已解析的顶栏、前景 token；不能拿本地偏好设置的底色代替网页顶栏。网页暂不可读时才用本地主题 fallback。Mac 不变。
